# Конференции.РФ

Учебный портал подачи заявок на конференции, форумы и семинары. **МДК 09.01 — Проектирование и разработка веб-приложений.**

**Выполнила:** Кукина Алла Владимировна, группа 4ИСП9-45. Москва, 2026.

**Стек:** Python 3, Flask, SQLite, Jinja2, HTML, CSS, JavaScript.

Роли: гость (каталог и регистрация), участник (заявки, просмотр статусов, отзыв), администратор (все заявки, фильтры, управление статусами). Статусы: `новая → назначено → завершено`.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py create-admin admin ПридумайтеСложныйПароль2026
python run.py
```

Открыть http://127.0.0.1:5000. Команда `create-admin` создаёт тестового администратора. **Не используйте приведённый пример пароля в опубликованных сервисах.**

Тесты: `python -m pytest -q`. База создаётся автоматически в `instance/` и не публикуется в Git.

## Структура

- `app/` — код Flask, маршруты, шаблоны и статические файлы
- `schema.sql` — база данных
- `tests/` — pytest
- `screenshots/` — снимки приложения (с описанием способа получения)
- `docs/` — учебное ТЗ и инструкция по сбору скриншотов
- `Отчёт МДК 09.01.docx` — отчёт по шести практическим
