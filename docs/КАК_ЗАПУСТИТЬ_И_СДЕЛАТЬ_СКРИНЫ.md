# Инструкция по запуску и подготовке снимков

1. Распакуй репозиторий `MDK.09.01` в папку на диске C или D.
2. Открой папку в проводнике, щёлкни по адресной строке, введи `cmd`, нажми Enter.
3. Выполни `py -m venv .venv`, потом `.venv\Scripts\activate`, потом `pip install -r requirements.txt`.
4. Выполни `python run.py create-admin admin ТВОЙ_ТЕСТОВЫЙ_ПАРОЛЬ_ОТ_8_СИМВОЛОВ` (один раз), затем `python run.py`.
5. Открой в Edge или Chrome `http://127.0.0.1:5000`.
6. Создай участника через «Регистрация», затем войди и создай заявку; для ошибок попробуй отправить пустую форму.
7. Открой второй браузер/режим инкогнито, войди под `admin`, открой «Панель», переведи заявку дважды: назначено, завершено.
8. Вернись участником, обнови «Мои заявки», открой «Оставить отзыв».
9. Для мобильных снимков нажми F12 → Ctrl+Shift+M → установи размер `390 × 844` → выбери меню ⋮ в инструменте снимка → «Capture screenshot» (или Windows Win+Shift+S).
10. Для практики 3.2 F12 → Network → поставь Preserve log → открой /login → введи тестовые данные → нажми «Войти» → найди POST /login → снимай вкладки Headers, Payload (пароль обязательно замажь!), Response, Cookies. Ни в одном скриншоте не должно быть сессионных токенов или паролей.
11. Для вывода тестов открой ещё одно окно cmd в папке проекта и выполни `python -m pytest -q`. Сними реальный результат, даже если есть ошибки, — потом исправим.
12. Скриншот коммитов делается уже после GitHub Upload: открой новый репозиторий и нажми Commits. При загрузке файлов через браузер одной операцией будет лишь один коммит — не заявляй 40+ коммитов.
