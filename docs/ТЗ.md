# Техническое задание — «Конференции.РФ»

**Цель:** автоматизировать регистрацию на конференции, подачу и обработку заявок, получение отзывов.

**Гость:** открывает каталог, карточку конференции, регистрируется, входит.

**Участник:** создаёт заявку с выбором конференции, помещения, оплаты и мест; видит свои заявки, изменяет и отменяет пока статус «новая», после статуса «завершено» оставляет единственный отзыв с оценкой 1–5.

**Администратор:** смотрит все заявки, фильтрует по ФИО, событию, статусу; переводит «новая → назначено → завершено»; удаляет заявку и её отзыв.

**Нефункциональные требования:** адаптивность до 390×844; SQLite и параметризованные SQL; хеш паролей, роли, проверка CSRF, cookies HttpOnly, SameSite=Lax; отсутствие реальных персональных данных в тестовом контенте.

**База данных:** users → requests ← events; statuses → requests; requests → reviews (1:0..1). Все связи описаны в `schema.sql`.
