# Практическая работа № 4. Подсистема безопасности ИС

**Цель:** Хеширование паролей, разграничение прав, CSRF, параметризация SQL и блокировка попыток входа.

## Ход работы

1. Открыла исходный код приложения и изучила структуру `app/`, `schema.sql`, `tests/`.
2. Реализовала и связала функции, относящиеся к этой практической.
3. Проверила поведение вручную и предусмотрела автоматические проверки.
4. После локального запуска проверю результат и добавлю скриншоты в этот каталог.
